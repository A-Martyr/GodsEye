# Roadmap

Phase 1: Deep Learning OCR Upgrade
- Replace classical morphological plate localization with a trained object detection model to achieve >90% accuracy.

Phase 2: Trajectory Reconstruction & GIS Mapping
- Build query-based tracking interface to reconstruct vehicle paths on the map with timestamps and camera locations.

Phase 3: Macro Traffic Analytics
- Implement aggregated traffic density, origin-destination pattern tracking, and bottleneck detection.

Phase 4: Real-Time Alert System
- Implement WebSocket/push notification alerts for blacklisted vehicles and route anomalies.
