# GodsEye - Smart City ANPR System
Status: FINALIZED

## Objective
Develop a robust, centralized AI software platform that processes multi-camera feeds across a city-wide ANPR network to track vehicles and analyze macro-level traffic movement.

## Core Requirements
1. High-Precision OCR Module (>90% accuracy in real-world conditions) - upgrade existing morphology pipeline to deep learning object detection.
2. Trajectory Reconstruction Engine - query-based tracking interface mapping vehicle paths chronologically on a GIS map.
3. City Traffic Analytics Dashboard - centralized GIS-integrated web platform displaying heatmaps, speeds, densities, and flow trends.
4. Alert System - real-time flagging of blacklisted vehicles and suspicious route anomalies.
