# GodsEye - complete dependency set for the .venv-paddle environment
# (the 91.0% real-photograph reader, anpr/anpr_ocr_reader.py)
#
# PYTHON 3.12 ONLY. paddle publishes wheels for 3.9-3.12; 3.13 is unreliable
# and 3.14 has nothing. Verify before installing:
#
#   .\.venv-paddle\Scripts\python.exe --version     # must say 3.12.x
#
# This file has no environment markers, so everything below actually installs.
# Install torch FIRST from the CPU index, then this file:
#
#   .\.venv-paddle\Scripts\python.exe -m pip install torch torchvision \
#       --index-url https://download.pytorch.org/whl/cpu
#   .\.venv-paddle\Scripts\python.exe -m pip install -r requirements-paddle.txt
#
# torch is kept out of this file on purpose: plain `pip install torch` on
# Windows/Linux pulls the multi-GB CUDA build from PyPI, and the reader pins
# the device to CPU anyway (anpr/anpr_ocr_reader.py:459).
#
# Known-good: paddle 3.3.1, torch 2.14.0, numpy 2.5.2, opencv 5.0.0.93,
