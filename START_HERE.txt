GodsEye - city-wide ANPR platform (SIH 2026, Team Prometheus)
===============================================================

Two ways to look at this.

1. JUST LOOK (no install)
   Open the pictures in  screenshots/  : the control room's map, a search for a
   misread plate and the route it rebuilds, the engine's measured accuracy, and
   the city analytics.

2. ACTUALLY RUN IT  (Python 3.11+, about 2 minutes)

   pip install -r requirements.txt
   python seed.py                          # generates a day of city traffic
   uvicorn api.main:app --port 8000        # the control room -> localhost:8000

   The neural plate reader needs PyTorch. It is optional - without it the
   platform falls back to a classical reader and still runs:
   pip install torch --index-url https://download.pytorch.org/whl/cpu

   The trained models are included (models/), so nothing has to be trained.

WHAT TO TRY FIRST
   - The map: the Kolkata camera network, roads coloured by congestion
   - Search a plate: take one from "Live reads" and type it with one character
     wrong - it still finds the vehicle and draws its route
   - Read a plate: pick a camera scenario (try "monsoon" or "far_lane") and
     read it
   - Insights: analytics, the engine's accuracy, incidents and the judge link

WHERE TO READ
   README.md          what it does, how it is built, and the measured accuracy
   RUN.md             running it, the judge link, checking it yourself
   AUGMENTATION.md    the camera model - why the training images are generated
                      by simulating a real pole-mounted traffic camera

VERIFY IT YOURSELF
   python tests.py                                  # 101 end-to-end checks
   python -m anpr.benchmark --samples 100           # measure the accuracy
   python -m anpr.camera_sheet                      # see what the camera model
                                                    # produces, side by side
